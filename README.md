A high-performance personal engineering portfolio showcasing distributed deep learning pipelines, production MLOps systems, and algorithmic research. 

Engineered with architectural modernism and computational rigor: uncompromised legibility, high typographic density without clutter, and deliberate high-contrast elements that reflect mathematical precision.

**Live Website:** [https://david-langat.github.io/Personal-Website/](https://david-langat.github.io/Personal-Website/)

---

## Key Features & Architecture

* **Apple-Inspired Bento Layout:** Clean surface boundaries, hairline dividers (`rgba(0,0,0,0.06)`), and low-amplitude ambient diffusion.
* **Frosted Translucent Header:** Ultra-light navigation bar (`backdrop-filter: blur(20px) saturate(180%)`) with quick navigation anchors, social channels, and responsive mobile adaptations.
* **Dynamic Repository Carousel:** Interactive snap-scrolling showcase with category filtering (MLOps, Distributed, Vision) and real-time commit activity charts.
* **Competition Benchmarks:** Validated machine learning competition profiles highlighting custom loss formulations, cross-validation schemes, and leaderboard metrics.
* **4-Column Technical Matrix:** Calibrated proficiency breakdowns across Deep Learning, Data & MLOps, Languages & Runtimes, and Cloud Infrastructure.
* **Terminal-Style Contact Form:** Client-side transmission channel with real-time UI state transitions.
* **Zero Overhead Delivery:** Clean, standalone production bundle optimized for global edge CDN distribution with zero layout shift and instantaneous load times.

## Design System

The visual philosophy follows the **Precision Algorithmic Portfolio** specification outlined in [`DESIGN.md`](DESIGN.md):

| Attribute | Specification |
| :--- | :--- |
| **Typography** | Headlines: `Geist` • Body: `Inter` • Telemetry / Code: `JetBrains Mono` |
| **Primary Accent** | Electric Azure (`#0071e3`) with focused hover states (`#0077ED`) |
| **Canvas Palette** | Base Canvas: `#fbfbfd` • Card Surfaces: `#ffffff` • Soft Tint: `#f5f5f7` |
| **Text Hierarchy** | Primary Obsidian: `#1d1d1f` • Subtext Slate: `#6e6e73` • Muted: `#86868b` |
| **Borders & Radii** | Hairline stroke `1px solid rgba(0,0,0,0.06)` • Corner radii: `1rem` to `2rem` |
